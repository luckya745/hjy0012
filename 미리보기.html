햄스터와 함께 탈출하기

이 앱은 일반 Hamster용입니다. Hamster S와 구분하여 제품 모델을 확인하세요. 충전용 USB 케이블만으로 PC 제어가 되는 것은 아닙니다. 전용 무선 USB 동글과 드라이버가 필요할 수 있습니다.

  1. 햄스터를 충전하고 전원을 켠 뒤 전용 동글을 PC에 연결합니다.
  2. Python 3을 설치하고 아래 실행 꾸러미를 내려받아 압축을 풉니다.
  3. py -m pip install -r requirements.txt를 실행합니다.
  4. py bridge.py를 실행하고 표시된 로컬 주소를 엽니다.
  5. ‘햄스터 연결’을 누르면 동글을 찾아 연결하고 햄스터 모드로 전환합니다.
실행 꾸러미 다운로드

온라인 페이지는 체험용입니다. 실제 교구 제어는 연결 프로그램이 제공하는 로컬 웹페이지에서 작동합니다. 다른 로봇 코딩 프로그램은 종료해 주세요.

평평하고 넓은 바닥에서 사용하세요. 좌우 반응은 제자리 좌·우 회전입니다. LED는 앞쪽 양쪽 LED이며 상단 충전·연결 표시등과 다릅니다.
